1. Background

Recreate the shell execution model

Bash의 핵심 동작을 재현하며, 문자열 입력이 명령어 해석·프로세스 생성·파일 디스크립터 연결로 이어지는 Unix 실행 모델을 구현했습니다.

2. Architecture

Component diagram

입력 처리부터 토큰화·파싱·실행 계획 수립을 거쳐 builtin 또는 Unix 프로세스 API로 이어지는 흐름입니다.

3. What I Did

Shell pipeline implementation

  • token, quote, pipeline 구조를 해석하는 scanner·parser 흐름을 구현했습니다.
  • 환경 변수와 경로 확장, builtin 명령을 분리했습니다.
  • fork(), execve(), waitpid() 기반 실행 흐름을 구성했습니다.
  • pipe와 리다이렉션별 파일 디스크립터 연결·정리를 구현했습니다.
4. Problem Solving

Pipeline and redirection

명령마다 다른 표준 입출력 구성

현상: ls | grep foo > result.txt처럼 파이프와 리다이렉션이 함께 있으면 명령마다 연결해야 할 fd가 달라집니다.

해결: 파이프 생성, dup2() 연결, 불필요한 fd 닫기, 자식 실행을 단계로 분리했습니다. 이 방법은 실행 경로마다 fd의 소유권과 종료 시점을 명확히 합니다.

5. Result

Interactive shell

  • builtin, 환경 변수 확장, 파이프, 리다이렉션, signal 처리를 포함한 interactive shell을 구현했습니다.
  • 프로세스 생명주기와 Unix I/O 모델을 하나의 실행 흐름으로 연결했습니다.
