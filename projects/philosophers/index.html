1. Background

Coordinate shared forks

여러 실행 흐름이 제한된 공유 자원을 동시에 요청할 때 생기는 경쟁 상태와 교착 상태를 제어하는 프로젝트입니다.

The setup

원형 테이블의 철학자는 생각하고, 양옆 fork 두 개를 모두 잡은 뒤 식사하고 다시 내려놓습니다.

The constraint

모두가 한쪽 fork만 잡고 다른 쪽을 기다리면 아무도 진행하지 못합니다. 핵심은 자원 획득 순서와 상태 접근입니다.

2. Architecture

Fork lifecycle and monitoring

한 철학자가 두 fork를 획득하고, 식사 상태를 갱신한 뒤 반납하는 흐름과 monitor의 검사 흐름입니다.

3. What I Did

Concurrent state management

  • 철학자별 실행 루틴과 식사·수면 상태를 구현했습니다.
  • fork 접근을 mutex로 동기화했습니다.
  • 시간 기반 상태 검사와 출력 동기화를 구현했습니다.
4. Problem Solving

Avoid deadlock

모두가 같은 순서로 fork를 잡는 상황

lock 획득 순서를 조정해 순환 대기를 끊고, 각 스레드의 상태 갱신을 mutex 경계 안에서 처리했습니다.

5. Result

Deterministic resource control

동시성 환경에서 시간, 상태, 공유 자원의 관계를 직접 구현하며 race condition과 deadlock을 다뤘습니다.
