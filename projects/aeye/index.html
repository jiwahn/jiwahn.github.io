1. Background

Operational UI for camera data

스마트 관제 환경에서는 실시간 카메라 피드와 사용자·리포트·검색 화면을 한 제품 안에서 일관되게 제공해야 합니다. A-EYE는 이 흐름을 담당하는 프론트엔드입니다.

2. Architecture

Frontend component boundaries

App Router가 화면을 구성하고, 공통 컴포넌트는 Recoil 상태와 API wrapper를 통해 백엔드 데이터에 접근합니다.

3. What I Did

Build the application surfaces

  • Next.js App Router 기반 페이지와 공통 레이아웃을 구성했습니다.
  • 로그인, 프로필, 리포트, 카메라 피드, 검색 화면을 구현했습니다.
  • Recoil로 UI 전역 상태를 관리하고 API 호출을 wrapper로 분리했습니다.
  • MUI와 Docker 기반 개발·배포 구성을 적용했습니다.
4. Problem Solving

Video search thumbnail cost

작은 썸네일에 원본 크기 canvas 사용

현상: CCTV 검색 결과의 썸네일 생성이 느렸고, 작은 화면 표시용 이미지에도 원본 영상 해상도와 같은 canvas를 생성하고 있었습니다.

선택 및 구현: 화질 요구가 낮은 thumbnail 경로의 canvas 가로·세로를 각각 1/4로 줄였습니다. 처리 화소 수를 93.75% 줄이면서도 목록 표시 용도에는 충분한 품질을 유지했습니다.

5. Result

Faster video search experience

  • 동일 로직 재현 실험에서 canvas 처리 구간 중앙값을 13.7ms에서 3.3ms로 75.9% 줄였습니다.
  • 12개 영상의 불러오기·탐색·canvas 처리를 포함한 전체 썸네일 생성 중앙값을 458.1ms에서 346.6ms로 24.3% 줄였습니다.
  • 교과목 A+와 대한전자공학회 인공지능학부생 논문경진대회 장려상을 받았습니다.
