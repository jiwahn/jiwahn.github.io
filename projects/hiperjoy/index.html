1. Background

Touch-free wall control

Hiperwall의 멀티스크린 환경에서 벽 상태, 카메라, 미디어 피드를 하나의 데스크톱 UI에서 확인하고 제어하는 MVP를 만들었습니다. Leap Motion 2 입력을 활용해 비접촉 상호작용 가능성도 검증했습니다.

2. Architecture

Desktop controller pipeline

Leap MotionRust / LeapCElectron + ReactHiperwall Controller
3. What I Did

Turn hand tracking into OS input

  • leaprs로 Leap Motion 서비스·디바이스 연결과 tracking event polling loop를 구현했습니다.
  • 손바닥 좌표, 손가락 상태, pinch distance, grab strength를 읽어 제스처를 판별했습니다.
  • 좌표를 화면 절대 위치로 변환하고 click, scroll, drag로 매핑했습니다.
  • 센서 인식과 OS 마우스 제어를 MouseOperation으로 분리하고 enigo로 입력을 발생시켰습니다.
4. Problem Solving

Continuous sensor frames, discrete UI events

한 번의 pinch가 여러 클릭이 되는 문제

현상: 하나의 손동작이 여러 tracking frame으로 연속 전달되어 pinch를 즉시 click으로 변환하면 중복 클릭이 발생했습니다.

선택 및 구현: 마지막 클릭 시각을 기록하고 300ms 이내의 추가 입력을 무시하는 debounce를 적용했습니다. drag는 is_dragging 상태로 관리해 grab 시작에 press 한 번, 유지 중 move, 종료에 release 한 번만 실행했습니다.

5. Result

Touch-free input prototype

  • 실시간 hand tracking으로 이동, 클릭, 드래그, 스크롤을 수행하는 Rust 기반 비접촉 입력 프로토타입을 구현했습니다.
  • 하드웨어의 연속 이벤트를 상태 기반 UI 입력으로 변환하는 이벤트 처리 흐름을 완성했습니다.
